# Changesets

이 폴더는 아직 릴리스되지 않은 변경 사항을 모아둡니다.

PR을 올리기 전에 변경 내용을 기록하세요:

```bash
npx changeset
```

- 변경 종류를 고릅니다: `patch`(버그·미세 수정) / `minor`(기능 추가, 하위 호환) / `major`(깨지는 변경)
- 한 줄 요약을 적으면 `.changeset/` 안에 마크다운 파일이 생성됩니다.

이 파일들은 main에 머지된 뒤 release 워크플로우가
버전을 올리고 `CHANGELOG.md`로 합치면서 자동으로 사라집니다.
즉, **개발팀에 "무엇이 어떻게 바뀌었는지" 전달하는 핸드오프 신호**가 됩니다.
